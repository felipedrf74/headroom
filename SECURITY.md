# Security

Headroom is a local macOS extra. It has no account and no server.

## What to report

- Unexpected network destinations
- Token, email, or name persistence in Headroom storage or logs
- A way to read another user's session files

## What not to report

- Quota numbers that look wrong because a provider API changed
- Gatekeeper warnings on an ad-hoc signed local build

## How to report

Use [GitHub Security Advisories](https://github.com/felipedrf74/headroom/security/advisories/new) on this repository.

Do not open a public issue with tokens, cookies, or session files.
